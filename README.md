图片拼接工具介绍：纯本地运行，支持精准去白边

这是一款免安装、纯本地运行的网页图片拼接工具。无需上传服务器，完美解决日常拼图（尤其是手机长截图拼接）时的边缘痛点。同时针对手机端进行了排版优化，预览区置顶，方便边调边看。

核心功能：

· 精准去白边/黑边：提供智能自动去边与手动微调双重方案。首创四方向精准裁剪，支持滑动条及数字输入，可精确到像素级切除上下左右的多余边缘（如手机状态栏、底部菜单），避免误伤图片本身的内容。
· 三大拼接布局：支持水平拼接、垂直拼接（适合长截图缝合）以及自定义列数（1-6列）的网格拼接。
· 移动端优化：在手机端自动将预览区置于屏幕顶部、操作面板下沉，调节参数时画面实时可见。
· 细节交互：上传列表自带图片缩略图；支持拖拽调整拼接顺序；所有间距、边距参数均支持直接输入精确数字；透明背景以棋盘格显示。
· 隐私安全：基于 Canvas 的本地处理，图片不会上传至任何服务器，断网也可使用。

使用方法：

1. 导入图片（支持多选或直接拖拽到网页）。
2. 在列表中拖拽调整图片拼接顺序。
3. 选择水平、垂直或网格布局。
4. 拼接长截图时，将图片间距设为 0，并通过“精准裁剪”的数字输入框或滑块切除多余边缘。
5. 点击下载，保存为高清无损的 PNG 图片。

适用场景：

手机长截图缝合、插画/漫画无缝拼接、社交媒体多图排版等。
